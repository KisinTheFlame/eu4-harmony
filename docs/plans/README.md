## Drawing

The accepted direction keeps the simulation and live GUI in one process; the separate drawing thread remains a fixed framework part. Full world double buffering and simulation relocation are not built. Any further separation needs a new ownership and synchronization argument, not the old aspiration that every role should never wait. See the [simulation/interface decision](../adr/2026-11-10-simulation-and-interface-take-turns.md) and [native frame lifecycle](../game/interface/frame-lifecycle.md).
