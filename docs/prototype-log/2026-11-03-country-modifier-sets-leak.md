# 2026-11-03 The sets of modifiers a country's modifiers leak (tested by me)

Experiments with the census (research/main-menu.md, "What the census counts of the interface" and "Who holds them"), then the repair of the sets of modifiers (`core/src/repairs.rs`). Seven processes, `eu4.exe` started directly, the playset as installed and the regional-combat extension loaded, `trace` builds with the census on, driven by `eu4-harmony game`. Each round: a load from the main menu of `法兰西1495_11_19` or `英格兰1444_11_11`, 30 days at speed 5, an in-game load of the other, 10 days, a return. The first six processes were backed up by hand as AGENTS.md says; the last ran under the game lock (`.claude/skills/game-lock`), which backed up and restored the player's files; the framework files were copied aside first each time.

- **What the census counted**: the windows a return's generation held at its world reset (484) were mostly the interface still in use; at the main menu, once it was gone, 75 stayed. A timeline of the interface's rebuilds and the idler switch showed why (research/main-menu.md).
- **Who holds the sets**: scanning every live block at the main menu, every control block left was held by a vector's buffer in a copied container, and the copies by almost nothing.
- **The repair**, three rounds: no crash; each world reset deleted 397 to 2,663 sets of modifiers, nothing logged about a set not deleted or not moved; `0x931698`, `0x93dcc8` and `0x8f4e6c` held no block of any generation at the main menu after.
- **The build with it**, under the game lock: five rounds, then a new game as France and its return. Every answer right, no crash, nothing logged about a set not deleted. Each reset deleted 397 to 2,713 sets. `0x931698`, `0x93dcc8` and `0x8f4e6c` were in no generation's leftovers. By generation, at each world reset, against the build before run the same way: 2.4, 4.7, 3.5, 5.9, 2.1, 4.6, 3.6, 6.0 and 2.3 MB for the second to the tenth, where they were 3.9, 6.7, 3.8, 6.1, 3.7, 6.7, 3.8, 6.1 and 4.1: 35.1 MB in all where it was 44.9, about 2 MB less a round.
- **Not seen in the running game**: a long game, where the country's modifiers are made again many times; ironman; the 20 rounds; the process's private bytes.
- **Cleanup**: each game was closed by ending its process. The hand backup's `-Restore` and the game lock's `-Release` each listed what the runs changed (the framework's logs, `pdx_login_cache.txt`, `settings.txt`, `shortcuts.txt`), put each back and found every file as the backup had it; the release freed the game. The framework files in the game folder were put back and compared equal. The experiments' code was taken out of `core/src/census.rs`, `core/src/lib.rs` and `core/src/safe_point.rs`.
