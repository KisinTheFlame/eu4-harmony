Whether a save carrying extension save data passes the check that decides whether a save was changed, which the run above could not see. One run of `eu4.exe` as above, with the same build, tracing `0x97500` and `0x14e3390`; the same playset, `compress_autosave=no`. Backups as AGENTS.md says, with the framework files installed in the game folder copied aside first. No input was sent to the game's window.

- **A save the game wrote with the entry**: from there to the autosave of 1445.7.1, "wrote the data of 1 extension(s)", and the checksum taken after it with the same 8-byte salt. The entry lay between `idea_dates` and `ai`. Loaded again: the check returned 1, both times, "data for 1 extension(s)", "restored 1 task(s)", nothing in `error.log`.
