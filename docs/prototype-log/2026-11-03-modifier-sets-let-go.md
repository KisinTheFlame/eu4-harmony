# 2026-11-03 The sets of modifiers let go when nothing lists them (tested by me)

The repair of the sets of modifiers again (`core/src/repairs.rs`), with the copies a country's modifiers had before they were copied over kept until the modifiers' next destructor, as their own set still lists them (research/main-menu.md, "What points to them"). Five processes under the game lock, which backed up and restored the player's files; the framework files in the game folder copied aside first. `eu4.exe` started directly, the playset as installed, `trace` builds (which log any set copied over that the modifiers' own set does not list), driven by `eu4-harmony game`. Rounds as in the acceptance: a load of `法兰西1495_11_19` from the main menu, 30 days at speed 5, an in-game load of `英格兰1444_11_11`, 10 days, a return, a new game as France, 10 days and a return.

- **With the census**, three rounds: every answer right, no crash; nothing logged about a set not deleted, not moved or not listed. Each world reset deleted 574 to 2,270 sets; none was waiting at a reset. `0x931698`, `0x93dcc8`, `0x8f4e6c` and `0x8ea643` were in no generation's leftovers; the generations left 2.1 to 2.4, 4.7 to 4.9 and 5.8 to 5.9 MB, as with the repair taken out.
- **Twenty rounds, twice**, the census off: every answer right, no crash, nothing logged about a set. Handles 1,048 to 1,070. Private bytes 3,999 MB after the first round and 4,436 MB after the twentieth, about 23 MB a round; then 3,965 and 4,435 MB, about 24.7 MB a round (28.6 MB without the repair).
- **Long and ironman**, the census on: France a year from 1495.11.19, an in-game load of England and half a year, a return; Castile's ironman save 30 days, the same save loaded again in the game (its ironman exit save written first), 10 days, a return; Austria's ironman save of 1724 30 days and a return. Every answer right, no crash, nothing logged about a set; the reset after France's year deleted 3,125 sets, after England's half year 5,577.
- **The sets that waited**, two rounds with a build that counts them: 131 to 274 of each reset's 576 to 2,253 sets were deleted once the modifiers that listed them went: those the repair taken out deleted at once.
- **Not seen in the running game**: multiplayer; a game of many years in one session; the player's own in-game load from the menu; the sets' values in the interface (the repair deletes only sets the game no longer uses, and changes no value).
- **Cleanup**: each game was closed by ending its process. The three framework files in the game folder were put back and compared equal to the copies taken before. Releasing the game restored the player's files, the ironman saves and the autosaves the runs rewrote among them, and found every file as the backup had it. Scripts and copies of the runs were deleted.
