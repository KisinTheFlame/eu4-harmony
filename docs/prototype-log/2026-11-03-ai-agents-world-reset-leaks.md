# 2026-11-03 The AI's agents a world reset leaks, and the monarchs (tested by me)

The repair of the AI's agents (`core/src/repairs.rs`; research/main-menu.md, "The AI's agents"), and experiments on the monarchs a country's history keeps, not kept. Seven processes, `eu4.exe` started directly, the playset as installed and the regional-combat extension loaded, driven by `eu4-harmony game`; backups as AGENTS.md says, the framework files copied aside first. Saves: `法兰西1495_11_19` and `英格兰1444_11_11`, time run at speed 5.

- **The first process ran a build without `trace`**, put in place by the tests built after it: six rounds of a load from the main menu, 30 days and a return, no census. Each reset deleted 519 or 749 agents of the AI; no crash.
- **With the census**, a `trace` build that also checked each agent before deleting it: eight rounds as above. No agent had a parent other than the top agent, none was on that agent's own list. `0x153a66` was in no generation's leftovers; each round left 43,400 to 43,800 blocks, 6.7 to 6.9 MB, where the stability runs' rounds left 46,000 to 47,600 and 8.2 to 9.3 MB. No crash.
- **The monarchs**: an experiment build deleting a history record's monarch as the record went, when the registry still found it by its ID, crashed the first in-game load (`0xc0000005` inside `0x5d0580`, which the framework's call caught; the game then hung). Counted without deleting, two rounds of a load, 60 days, an in-game load, 10 days and a return: the characters' manager deleted 12,535 monarchs at each load from the main menu, the ones the records hold among them. Deleting only those not on the vector of all monarchs crashed the in-game load the same way, in the next process. Not repaired (research/main-menu.md, "The monarchs a history keeps").
- **As built**, the build kept, with `trace` and the census: five rounds of a load, 30 days, an in-game load of the other save, 10 days and a return, then a new game as France and a return: every answer right, no crash, nothing logged about an agent not deleted. Each in-game load's reset deleted 518 to 520 agents (法兰西) or 748 to 750 (英格兰), the new game's return 68. `0x153a66` was in no generation's leftovers: a return's generation left 42,300 to 44,400 blocks, 6.5 to 6.9 MB, an in-game load's 27,400 to 28,900, 4.0 to 4.2 MB (it was 5.2 to 6.6 MB).
- **Not seen in the running game**: the process's private bytes and the GUI root's elements, which this change does not touch; ironman; the 20 rounds; a country's AI let go outside a world reset.
- **Cleanup**: each game was closed by ending its process. `-Restore` listed what the runs changed (the framework's logs, `continue_game.json`, `pdx_login_cache.txt`, `settings.txt`, `shortcuts.txt`, the three autosaves), put each back, removed the two crash folders of the monarch experiments, and found every file as the backup had it. The framework files in the game folder were put back and compared equal. The experiments' code was taken out of `core/src/repairs.rs`.
