# 2026-10-30 An outline around system glyphs on the map (tested by me)

The map fonts of the game and of the Chinese language mod draw their names inside a soft grey band (see [research/font-textures.md](../research/font-textures.md)); system glyphs on the map had none. Two runs of `eu4.exe`, started directly, Chinese playset with the unchanged regional-combat extension, at 3840x2160, each from the main menu into a new game as Ming (`menu.start MNG`), the start-of-game introduction closed, the camera on province 2130 at a height of 650, never unpaused. This branch's build, after the build, the tests and the offline checks against `eu4.exe` passed. Framework settings for the first run: system fonts, Microsoft YaHei for text, KaiTi for the map, no `map_outline` line (so the default, the outline); for the second, bitmap fonts. Backups as AGENTS.md says, with the framework's whole folder in the user folder, every file at the top of it and the framework files installed in the game folder.

- **Startup**: 579 dependency points match; 106 hooks, 4 writes.
- **The pages**: system fonts, "system page 4864x4864 for "KaiTi" at 88.0 px ..., ink 100c10, outline 838183, 6 px" (4096 before, made larger by the outline on both sides); the five Microsoft YaHei pages "outline none". Bitmap fonts, "grown DXT5 page 6400x8688 for "KaiTi" ..., outline 838183, 6 px", the rest "outline none".
- **The settings window**: in the main menu it shows "地图文字包边" with "与游戏地图字体相同" under the map font; it was closed with Escape, unsaved.
- **The map**: with system fonts, 叶尔羌, 撒里畏吾尔, 哈密, 明 and the smaller names have the band: a faint grey glow on the white of Yarkand, a lighter edge on the yellow of the Uyghurs. With bitmap fonts, the mod's own glyphs at the same place look the same way; the system glyphs' strokes are thinner, KaiTi's being lighter than the mod's font.
- **Not seen in the running game**: a character the Chinese language mod's map font lacks, drawn with the outline into its grown DXT5 page (none came up on the map looked at; the page got the outline, and the two-color DXT5 blocks have a unit test); "None" chosen in the settings window (unit tests of the setting); the game's own `Mapfont.dds` with its 11 mip levels, read for its `H` with the system font look (the English playset was not run; an ignored test reads its outline from the installed game's file); a map page filling up.
- **Cleanup**: each game was closed by ending its process. `tools/player-state.ps1 -Restore` put back `pdx_login_cache.txt` and the framework's `settings.txt` and found every file as the backup had it; the framework's logs, the files at the top of the user folder and the framework files installed before the run were put back and compared equal to the backup. No save was written and no crash folder made. The backups and screenshots of the run were deleted. `player-state.ps1`, as this branch had it, stopped at the game folder's empty `userdir.txt` and was run with `-UserDir`; master had fixed it by then.
