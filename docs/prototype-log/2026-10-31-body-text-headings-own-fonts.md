# 2026-10-31 Body text and headings in fonts of their own (tested by me)

Body text and headings (GLOSSARY) now draw in system fonts of their own, told apart by the font's name, which the framework reads at `font+0x18` as the page loads. One run of `eu4.exe`, started directly, Chinese playset with the unchanged regional-combat extension, at 3840x2160. This branch's build, from before master's font weights, after the build, the tests and the offline checks against `eu4.exe` passed. Framework settings: system fonts, `body_font` FZPingXianYaSongS-R-GB, `heading_font` FZYaSongS-B-GB, `map_font` FZShengShiKaiShuS-EB-GB, the outline: the faces the Chinese language mod's own fonts were made from. Backups as AGENTS.md says; the framework files installed in the game folder, another branch's build, were copied aside first.

- **Startup**: 580 dependency points match; 106 hooks, 4 writes.
- **The names**: the six pages were made for `standard_font`, `ToolTip_Font` and `Arial12` (Body, in PingXian YaSong), `standard_22` and `Main_24` (Heading, in Cu YaSong) and `tahoma_60` (Map, in ShengShi KaiShu): each page's first font, by the name the game gave it. `standard_22` loads the mod's `zh-hans-18`, the file `vic_22` loads too, on 18-pixel lines. No font drew from a page in another family than its own, and no page was left as it was. So the name is in place when the page loads, which had been read only from the code.
- **The main menu**: 教程 and 退出 (text boxes in `vic_22`) and 鸣谢 and 选项 (buttons in `vic_22`) are in the bold face, the buttons a little softer, as they are drawn through their own texture; the version line (`vic_18`) is in the lighter one.
- **A game**: `menu.start MNG`, never unpaused. In the start-of-game introduction the title (`vic_29`), the tabs, the heading 大明, the description and 不再显示 (all `vic_22` in `startup_screen.gui`) are in the bold face, as the mod draws them; the Close button and the outliner (`vic_18`) in the lighter one.
- **Not seen in the running game**: the settings window and its new list (not opened; the setting's round trip has a unit test); bitmap fonts, where the split picks only the family characters the mod's fonts lack are drawn in; the English playset, whose headings are on lines of 20 to 36; a font with a name the game does not have, or a page shared by body text and headings (unit tests of `kind`); master's font weights together with this change.
- **Cleanup**: the game was closed by ending its process; no save was written and no crash folder made. `tools/player-state.ps1 -Restore` listed what the run changed (the framework's logs and settings, `pdx_login_cache.txt`, `settings.txt`, `shortcuts.txt`), put each back and found every file as the backup had it. The three framework files in the game folder were put back and compared equal to the copies. The backups and screenshots of the run were deleted.
