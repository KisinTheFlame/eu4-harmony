# 2026-10-30 System fonts at the window's density (tested by me)

The game ran at 3840x2160 with the interface scale at 1.5 (`game_ui_scale` in `settings.txt`), where the player found Microsoft YaHei badly drawn. Four runs of `eu4.exe`, started directly, Chinese playset with the unchanged regional-combat extension; each went to the main menu, then `menu.start MNG` into a new game as Ming, never unpaused, with a screenshot of each through `eu4-harmony game screenshot`. Framework settings for the first three: system fonts, Microsoft YaHei for text, STLiti for the map; for the last, the player's own (bitmap fonts). The first run was the framework build installed before (for comparison), the other three this branch's, after the build, the tests and the offline checks against `eu4.exe` passed. Backups as AGENTS.md says, with the framework's whole folder and its installed files in the game folder.

- **Startup**: 579 dependency points match; 106 hooks, 4 writes.
- **The pages**: five of Microsoft YaHei, at 13.6 to 27.3 px, "1.50 px a GUI unit"; the map's STLiti at 1.00. In the second run they were 1024 pixels square, like the first's; from the third on 1536, each adding 9 MB of private bytes as it was created instead of 4. With bitmap fonts the six grown DXT5 pages were as before, at 1.00.
- **Before**: every system glyph was the page's pixels stretched 1.5 times by the linear filter: soft, its strokes uneven in weight. That was the whole of what the player saw; the glyphs themselves were anti-aliased, across only.
- **After**: the start-of-game introduction, the window's title, its tabs and its Close button, the outliner, the top bar's numbers, the main menu's buttons, the continue box and the version line are all sharp, at the size and place they had. The tabs, the Close button and the main menu's buttons are drawn through their own texture, now made 1.5 times as large: not cut off, not moved.
- **Line breaks**: the introduction's first line holds two characters more ("纷争"): a glyph's advance is now rounded to page pixels where it was rounded to GUI units, and the characters of that text came out about a pixel narrower each.
- **Bitmap fonts**: the introduction, the tabs and the outliner looked as with the build before; not compared pixel by pixel.
- **Not seen in the running game**: tooltips, event windows, the lobby and edit boxes with the change; the interface scale changed while the game runs (pages keep the density they loaded with); a scale of 1 or below (density 1, so nothing changes; not run); floating text; a page filling up; the game wanting textures in powers of two (unit test only); whether horizontal strokes look softer than with anti-aliasing across only at the sizes YaHei's own table hints (20 px here), which was judged from a rendering outside the game.
- **Cleanup**: each game was closed by ending its process, which left `graceful_exit=no` in `settings.txt`; that file, `pdx_login_cache.txt` (rewritten by the game) and the framework's logs were put back from the backup, and every backed-up file compared equal to it; no save was written and no crash folder made. The framework files installed before the run were put back in the game folder; the backups and screenshots of the run were deleted.
