# 2026-11-02 The companies' leaders and the rebel factions a world reset leaks (tested by me)

The repairs (`core/src/repairs.rs`): a mercenary company's leader deleted as the company's destructor begins, and every country's rebel factions deleted as the world's clear begins; the framework's other fixes of the game's defects moved into the same module. Seven processes, `trace` build, the census on; backups as AGENTS.md says, the framework files copied aside first. Driven by `eu4-harmony game`. Saves: `英格兰1444_11_11` and `法兰西1495_11_19` (no ironman), time run at speed 5.

- **The first build** deleted each country's factions at that country's clear. One process: a load from the main menu, three in-game loads of `英格兰1444_11_11`, two of `法兰西1495_11_19`, 90 days, a return, a load. Each reset deleted 2,275 companies' leaders and 806 factions (英格兰), 2,375 and 1,056 (法兰西), 2,377 and 1,053 (法兰西 after 90 days); the census found `0x7528c3` gone and `0x861d41` down to 34 to 158 blocks, a load leaving about 16,400 blocks, 2.7 to 3.2 MB (it was 26,050 and 3.6 MB).
- **A leader held twice**: the game's own records of a leader (a country's history) are destroyed late in each country's clear; a faction whose leader went over to another country could lose it to that country's clear first. An experiment build checked each leader before the framework deleted it (its class, and the registry finding it by its ID): of 543 and 551 the factions held, none had gone. The build kept deletes the factions before any country is cleared, as the world's clear marks the world as being cleared (research/main-menu.md).
- **The kept build**: 法兰西 loaded, 90 and then 30 days run, an in-game load of 英格兰: that reset deleted 2,377 leaders and 1,058 factions, with the rebels' armies still there, and went on; 英格兰 loaded, a return (2,275 and 806), no crash until the load that followed.
- **A return after time ran crashed** in all six runs that did one: after 法兰西 ran 21 to 120 days, a return and a load from the main menu crashed the game (`0xc0000005` in `d3d9.dll`, under `SetTexture`) in the main menu or in the loaded session's first frames; the game's crash handler then hung, and the process was ended. A sprite the session left in the GUI root was drawn with its sprite object freed (research/main-menu.md). With the companies' and factions' repairs off, with the session interface's repair off, and with the still notice off (one run each), it crashed the same: not this change. Open.
- **`menu.load` answered "only in the main menu"** twice in a game, right after a `time.advance` had answered, and worked when asked again: the race seen before after `menu.start`. Open.
- **Not seen in the running game**: a country's clear outside a world reset (`0x75d1e0`), whose factions the framework leaves; ironman saves; the 20 rounds.
- **Cleanup**: the experiment builds' code (the checks before deleting, the switches to turn each repair and the still notice off, the census of history records) was taken out. `-Restore` listed what the runs changed (the framework's logs, `continue_game.json`, `pdx_login_cache.txt`, `settings.txt`, `shortcuts.txt`, the three autosaves), put each back, removed six crash folders, and found every file as the backup had it. The framework files in the game folder were put back and compared equal. A process dump written for the first hang was deleted.
