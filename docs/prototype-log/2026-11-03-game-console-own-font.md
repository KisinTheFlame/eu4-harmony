# 2026-11-03 The game console's own font (tested by me)

This way of giving the console a font of its own was given up for framework files the same day ([ADR framework-files-in-the-game-file-system](../adr/2026-11-03-framework-files-in-the-game-file-system.md), the next section); the settings and the settings window are the ones it tried.

The game console draws in a font of its own, `eu4harmony_console`, a copy of `Arial12` whose path starts with `/`, in the console font of the framework settings (Consolas by default). Two runs of `eu4.exe`, started directly, this branch's build after the build, the tests, clippy and the offline checks against `eu4.exe` passed; the player's playset (the Chinese language mod, whose `Arial12` loads `gfx/fonts/zh-hans-12`) with the unchanged regional-combat extension, the player's framework settings with no console font in them, 3840x2160 at an interface scale of 1.5. The game was claimed with the `game-lock` skill, which backed up the player's files; the framework files installed in the game folder, another branch's build, were copied aside first. Each run: the main menu, `menu.start FRA`, the console opened with the key left of 1 (a scratch script, since `tools/game-input.ps1` has no key for it), `help cash` run and `echo 中文 ABC 0123 iIl1` typed, screenshots through `eu4-harmony game screenshot`.

- **Startup**: 712 dependency points match; 120 hooks, 10 writes.
- **The order of the files**: the mod's `interface/core.gfx` was spliced (18989 to 19178 bytes), the console font's page made, and then the game's `interface/core.gui` (6949 to 6971 bytes, the two fonts' names 11 bytes longer each): the `.gfx` files are read before the `.gui` files, as the console font needs.
- **Pages of their own**: `Arial12` got a 1536x1536 page in the body text font (FZPingXianYaSongS-R-GB) and `eu4harmony_console` another in Consolas 400 at 15.4 px. So a path written with a leading `/` is a texture of its own, and the game read the font's files through it: the page loaded and drew.
- **The console**, first run: the help text and the edit box in Consolas, monospaced, `0`, `i`, `I`, `l` and `1` told apart; 中文 in Microsoft YaHei, the fallback, whole on the console's 16-unit lines. The strength of armies on the map (`Arial12` too) stayed in the body text font.
- **The settings window**, after `menu.return` (an in-process return): 控制台字体 Consolas and 控制台字重 Regular below the map's outline; the console's list held fonts without Chinese (Cascadia Code, Cascadia Mono, Courier New and the like). Cascadia Mono was chosen and saved: the framework's `settings.txt` got `console_font="Cascadia Mono"` and `console_weight=400`.
- **Second run**, with that file: the console's page in Cascadia Mono 400 at 15.5 px, and the console drew in it.
- **Not seen in the running game**: the console in the main menu (the key did not open it there; after the in-process return the console opened in the session showed over the main menu, which was not looked into); a mod whose `core.gfx` has no `Arial12` or whose `core.gui` lacks the console's windows (unit tests only); the vanilla fonts without the Chinese language mod; another console weight than Regular; an interface scale of 1.
- **Cleanup**: each game was closed by ending its process. The framework files copied aside were put back and compared equal by hash; releasing the claim put every player file back (the framework's `settings.txt` and logs, `settings.txt`, `pdx_login_cache.txt`), compared them with the backup and removed it. No save was written, no crash folder was made. The scratch script, screenshots and copies were deleted.
