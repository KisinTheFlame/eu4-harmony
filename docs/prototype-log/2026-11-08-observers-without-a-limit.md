# 2026-11-08 Observers without a limit (tested by me)

Observers made at run time, any number of them, in place of the 96 compiled ones (`core/native.cpp`, `core/observer.asm`, `core/src/hooks.rs`): each observer's stub, 32 bytes written when it is made, pushes the observer's slot and jumps to one entry all observers share, which hands the call to `eu4h_observe` and puts back the integer registers the caller had, but for the result. A developer build with the test games' pipes, the heap census and the call trace, in a claim's test game started hidden; the save `observer-1700.1.1` (TUR, observed with `console run observe`), the player's playset with Regional Combat; dev.toml tracing twelve game functions, each as `RVA:12`, the first 3 calls of each: `0x107ec0`, `0xd4cbc0`, `0x1034f0`, `0x1a8b00`, `0xed7b0`, `0xf70d0`, `0xd511a0`, `0x359e20`, `0x1032f0`, `0xcfd70` (the date's year), `0xcfe10`, `0xd4c060`.

- **Past the old limit**: the build's own observers are 85 (80 in a player build, the census's 5), so with the twelve traced 97 functions were observed, one more than the 96 slots there were. Startup: "1711 dependency points match; 231 hooks, 12 writes".
- **The first start crashed** before the main menu, at `eu4+0xa7b741` writing `core+0x187d10`. The caller of the date's year, `0xa7b710`, keeps its object in r10 across `call 0xcfd70`, which leaves r10 alone: the game's code, compiled as a whole, may count on a function it calls leaving a volatile register as it was. The stub then put the slot in r10. Since then the stub pushes it, and the entry gives r10, r11 and the argument registers back as they came; the test `an_observer_leaves_the_caller_s_registers` calls through a caller that does the same and fails without it. Whether the compiled observers before this broke `0xcfd70`'s caller too was not tried; they ran Rust code, which uses those registers, around the original.
- **The second start**: the main menu after 64 s; `menu.load observer-1700.1.1`, `console run observe`, `time.advance` 60 days at speed 5, to 1700.3.2, a `day` event each day (the daily update's observer). Every one of the twelve traced functions logged its calls, its arguments and its result ("later calls not logged" for each); no fatal, panic or error in the log, no crash folder of the second start.
- **Not tried**: a player build in the game (its 80 observers are fewer than the old limit, and the tests run the same code); a function with floating-point arguments or result, which an observer did not forward before either; sampling with `cargo xtask profile` while a thread is in a stub or the entry.
- **Cleanup**: the claim released; the second game ended by the release. dev.toml and the scratch files deleted.
