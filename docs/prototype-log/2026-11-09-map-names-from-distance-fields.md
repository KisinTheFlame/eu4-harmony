# 2026-11-09 The names on the map drawn from distance fields (tested by me)

D1 to D3 of [plans/map-names-distance-fields.md](../plans/map-names-distance-fields.md) on a test game: a developer build of this branch with the test games' pipes, master merged; the player's playset (the Chinese language mod, the map font FZShengShiKaiShuS-EB-GB at 78.2 pixels), every DLC, 3840×2160 at an interface scale of 1.5. The machine was busy throughout: the player's own game and two other sessions' test games ran beside it, and the framework's line breaks took 1.6 to 22 µs each from start to start.

- **The page and the shader**: the log said "holding distance fields of spread 8, with mip levels" for `tahoma_60`'s page (outline `838183`, 6 pixels) and "spliced gfx/FX/mapname.shader … 2377 -> 3436 bytes" as the map was set up; with `map_outline=no`, spread 4 and 3043 bytes. The page grew once before the main menu, from 2560×2560 to 2560×5120, as before.
- **Drawn**: a new game as the Ottomans, the camera on Constantinople (`camera.look_at 151`) at the heights 50 (the closest), 310, 1200 and 3000, a screenshot at each. At 50 the province names' edges were sharp at the screen's pixels with the outline's soft band around them, where the same view built from master at `967dd5bd` showed blurred edges with the steps of bilinear magnification along the slanting strokes; without the outline, sharp black ink. At 1200 and 3000 the small country and province names were as legible as before and their edges smooth.
- **Costs**: starts alternating master's core and this branch's, twice each: every glyph drawn to the main menu in 0.87 and 1.8 s against 1.4 and 1.7 s, within what the busy machine made of the same build. Timed inside the map font's glyphs (a build with timing added, removed afterwards), 1,100 glyphs took 0.77 to 1.12 s in DirectWrite, 0.27 to 0.32 s making the fields and 0.06 to 0.08 s putting them in the page; with mip levels, 200 glyphs took 3.5 ms to put. The page's growth took 2 to 6 ms with mip levels, against 0.3 to 0.5 ms before.
- **Not measured**: the frame time at the closest zoom (the owner asked for an estimate instead: the shader's 28 more instructions, on the names' pixels only); the names while the camera moves, for shimmering (screenshots only).
- **Not verified**: a lost device and its reset; a mod whose `mapname.shader` reads the page otherwise (unit tests only: the shader is then left alone and the page holds colors); the game's own `Mapfont` without the Chinese language mod; `-opengl`.
- **Crashes**: three starts of this build crashed in the map logic before master took out the mesh types beside the databases ([the crashes](2026-11-09-mesh-types-crash-in-the-map-logic.md)); none after, and none in the map names' code.
- **Cleanup**: the test game released, its logs and crash folders kept in the claim's `kept\`; the screenshots kept in the session's scratchpad only.
