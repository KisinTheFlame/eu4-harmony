# 2026-11-01 Light text drawn as a blend in light would show it (tested by me)

The player found body text in FZ PingXian YaSong far from how the Chinese language mod draws it in the same face. System glyphs for light text are now drawn with the alpha that gives over black what a blend in light would, and fonts drawing dark text from the same page get glyphs of their own, with their coverage as it was. Three runs of `eu4.exe`, started directly, Chinese playset with the unchanged regional-combat extension, at 3840x2160 with the interface scale at 1.5, the player's framework settings: body text in FZPingXianYaSongS-R-GB 400, headings in FZYaSongS-B-GB 400, the map in FZShengShiKaiShuS-EB-GB 400. The first run was master at `0dd80ca` (577 dependency points match), with system fonts; the second this branch's build, after the build, the tests, clippy and the offline checks against `eu4.exe` passed, with system fonts; the third the same build with bitmap fonts, to see the mod's own pages. Each went to the main menu, then `menu.start MNG`, `console run event flavor_mng.1`, a click on the start-of-game introduction's Close button (the game window checked to be in front first), and screenshots through `eu4-harmony game screenshot`. Backups as AGENTS.md says; the framework files installed in the game folder, another branch's build, were copied aside first.

- **Startup**: 579 dependency points match, the font color's two among them; 105 hooks, 4 writes.
- **The tones**: the log names the first font to draw each tone from each page: `standard_font`, `ToolTip_Font`, `standard_22`, `Main_24` and `Arial12` light, in `ffffff`; `vic_18_black`, `Main_16_black`, `mapfont_small` and `Main_24_black` dark, in `000000`, from the pages the light ones made; `tahoma_60` dark, in the map page's `100c10`.
- **Dark text**: the event window's description (`vic_18_black`, black on parchment) is the same as on master to the pixel (none of 67,824 pixels differs).
- **Light text**: the tooltip (`ToolTip_Font`), the event's options (`vic_18`), its title (`vic_29s`) and the introduction's description (`vic_22`) are brighter, their edges fuller; the tooltip's text changed in 19,801 of 73,440 pixels, the most by 169 of 255. The headings in FZ Cu YaSong, mostly whole pixels already, changed less to the eye.
- **Against the mod's pages**: its body text is still clearly heavier, light and dark alike: the tooltip, the options and the event description. Its event title looks much as the framework's.
- **Not seen in the running game**: the framework UI (the settings window was not opened; its glyphs take the light tone in a unit test only); the map's names (the map was not drawn by the time of the screenshots); the ledger; colored text inside a light font, which takes the font's tone; a system glyph filling a character the mod's pages lack in the third run, as none was looked for; the English playset; an interface scale of 1.
- **Cleanup**: each game was closed by ending its process; no save was written and no crash folder made. `tools/player-state.ps1 -Restore` listed what the runs changed (the framework's logs and settings, `pdx_login_cache.txt`, `settings.txt`, `shortcuts.txt`), put each back and found every file as the backup had it. The three framework files in the game folder were put back and compared equal to the copies. The worktree master was built in was removed; the backups and the screenshots were deleted, but for a sheet of crops kept outside the game, user and repository folders for the report.
