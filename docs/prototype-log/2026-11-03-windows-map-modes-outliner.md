# 2026-11-03 The windows a return leaves, the map modes' window and the outliner's entries (tested by me)

An experiment build listing the GUI objects a return leaves (research/main-menu.md, "Which windows stay"), then the repairs of the map modes' window and the outliner's entries (`core/src/repairs.rs`), with experiment switches turning each off, not kept. Nine processes, `eu4.exe` started directly, the playset as installed and the regional-combat extension loaded, `trace` builds with the census on, driven by `eu4-harmony game`; backups as AGENTS.md says, the framework files copied aside first. Each round: a load from the main menu of `法兰西1495_11_19` or `英格兰1444_11_11`, 30 days at speed 5, an in-game load of the other, 10 days, a return.

- **The windows that stay**: two and three rounds with the listing, each return leaving 1,430 to 1,730 more objects in the GUI root than the one before; the windows among them are in research/main-menu.md.
- **The outliner's entries deleted before it went**: the first in-game load crashed as `0x81dc30` killed the outliner's windows (`0xc0000005`, found by scanning the main thread's stack in the minidump, which held no exception context). **Deleted after it went**, all of them or only its headers: the game ended soon after the in-game load read its save, without a crash folder (the event log: `0xc0000374` in `ntdll.dll`). With the outliner's repair off and the map modes' on, three rounds ran, no crash. Logging the entries without deleting them showed which hold windows.
- **As built**, telling `+0x4b0` first as the outliner's refresh does: three rounds, then, with the build kept, five rounds and a new game as France and its return. Every answer right, no crash, nothing logged about a window not killed or an entry not deleted. Each outliner went with 37 (英格兰) or 48 (法兰西) entries deleted. `mapmode_entry`, `mapmode_more_window` and `outliner_header_entry` were in no round's leftovers in the GUI root, which grew by 1,170 to 1,360 objects a round. The census: a return's generation left 41,000 to 44,400 blocks, 6.1 to 6.7 MB (it was 6.5 to 6.9 MB), an in-game load's 26,500 to 27,900, 3.7 to 4.1 MB (4.0 to 4.2 MB); the windows' blocks (`0x155c294`) 484 or 485 a return's generation, where they were 541.
- **Not seen in the running game**: the map modes' panel opened by the player before a rebuild; the outliner with the player's armies and fleets in it after a long game; ironman; the 20 rounds; the process's private bytes.
- **Cleanup**: each game was closed by ending its process. `-Restore` listed what the runs changed (the framework's logs, `pdx_login_cache.txt`, `settings.txt`, `shortcuts.txt`), put each back, removed the crash folder of the first outliner try, and found every file as the backup had it. The framework files in the game folder were put back and compared equal. The experiments' code was taken out of `core/src/census.rs`, `core/src/safe_point.rs` and `core/src/repairs.rs`.
