# The regional-combat port lives outside the framework repository

The framework repository holds only the proxy, the core, the SDK and the scaffold (the minimal example is generated by the scaffold). Once regional-combat is ported to a mod, it stays in its own repository and depends on the SDK as an outside developer would. This way the port also tests the whole experience of developing a mod outside the framework repository, and keeps regional-combat's particular needs from seeping into the framework.
