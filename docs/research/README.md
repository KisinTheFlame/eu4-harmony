# Research evidence

Independent investigation and measurement evidence supporting the [game-system accounts](../game/README.md). Native logic lives in those topics; the address index links only there. These summaries retain historical conditions, significant results, failures and limits, not every command or successful screenshot.

- [Performance and concurrency](performance-evidence.md): startup, P99 comparisons, saves, random order, failed parallelism and memory probes.
- [Interface and drawing](interface-evidence.md): text/input, rendering races, highlights, tooltip and ordering observations, and unreproduced message buttons.
- [Capabilities and mechanics](mechanics-evidence.md): commands, extension data/reload, achievement tracking, native mechanics, mercenaries and center references.
- [Mercenary-name bytes](mercenary-company-names.md): the observed byte loss and character-boundary repair limits.
- [Reformation-center crash](reformation-center-crash.md): captured object identity, exception chain and causal uncertainty.
- [Mercenary-discipline report](mercenary-discipline.md): supplied-save inputs, missing mods and representative panel versus calculated regiment value.

Routine builds, unit tests and repeatable regressions belong in PR validation descriptions. Add or extend evidence here only when the finding has lasting value beyond the code/tests. Keep screenshots only when their pixels supply evidence that text cannot replace.
