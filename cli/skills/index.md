eu4-harmony skills: guides for making an EU4 Harmony mod

Read the guide for the work in front of you before writing code for it. Each
names the steps and the checks that tell you a step is done. For what a
capability takes and answers, read eu4-harmony wiki; these guides point into
it rather than repeat it.

usage: eu4-harmony skills [<topic>...]

topics:
  mod            making a mod, from eu4-harmony new to a package to upload
  tasks          waiting for an answer, several things at once (spawn, async, await), cancelling
  state          keeping state: save data in the save, files in the data folder, the scripts' flags and variables
  ui             interface fragments: elements in the game's windows
  ui buttons     a button in the army panel's button area
  ui windows     windows and pop-ups of the mod's own, in the game's look
  ui design      an interface the player takes for the game's own
  localisation   texts in the player language
  testing        tests against a fake game, run by eu4-harmony test
  game           trying the mod in the running game through remote control
